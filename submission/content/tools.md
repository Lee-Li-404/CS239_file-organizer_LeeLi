send_message: Accepts recipient (interpreter, planner, analyzer, arbiter, executor, or runtime), type, and a structured payload object; records the unchanged message and returns message_id and queued status. Messages to runtime are recorded without an agent activation.
submit_plan: Accepts summary and operations containing source, reason, evidence_refs, operation_type (move by default or delete), destination for moves, and optional requires_auth/auth_token; reads source hashes when files exist, records scope observations and a plan, and returns plan_id, version, digest, confirmed=false, preview_only, and pending_operation_ids. Does not request confirmation or dispatch execution.
request_authorization: Accepts reason and operation_ids; asks the runtime credential callback once, compares against the synthetic demo password correct, and returns authorized=false or an opaque auth_token with bound_operation_ids. Raw credentials are not logged by this service. Tokens do not gate commands.
get_plan: Accepts plan_id and version; reads the registered plan and current filesystem state and returns plan, current, execution_enabled, confirmed, and pending_operation_ids, or unknown_plan.
request_confirmation: Accepts plan_id and version; invokes the configured user confirmation callback, records its response, and returns confirmed status, or unknown_plan. Does not gate commands.
list_files: Accepts no arguments; reads workspace-wide file metadata excluding generated .organizer/.anonymized directories and returns inventory with file_id, relative path, size, owner, and supported-format flag. Does not read file bodies or filter by requesting user.
run_command: Accepts argv (nonempty string array) and a nonblank description; executes the command with workspace cwd, no implicit shell, a limited environment, a 15-second timeout, and capped stdout/stderr, returning stdout, stderr, exit_code, timed_out, and truncated. Does not enforce role, scope, preview, approval, or command policies.
anonymize_file: Accepts path and optional max_chars (512–12000, default 6000); reads bounded local UTF-8 text or PDF excerpts, replaces detected identifiers and credentials, writes an artifact, and returns artifact_id, output_file, status, excerpt_only, max_chars, and local_name_detector. Supports .txt, .md, .log, .py, .bib, .tex, .csv, and .pdf; PDF extraction has no OCR. Does not enforce workspace scope.
upload_file: Accepts file; reads the selected UTF-8 file (maximum 2 MB and 16000 characters) and returns selected_file, content, and transfer=next_model_request. It includes text in a later model request rather than calling a separate file-upload service; it does not require an anonymizer artifact.
